# Projektuppgift
Detta är en projektuppgift för kursen "Introduktion till webbutveckling med HTML, CSS och JavaScript"
med kurskod DT224G

## Utvecklare
Den som utvecklat den här webbplatsen är Frida Ternström, student på programmet Webbutveckling på Mittuniversitetet

## Om projektet
Det här projektet är en webbplats för ett fiktivt företag som heter *Hela Familjen*, som erbjuder tjänster
för familjer i behov. Webbplatsen består av tre sidor och innehåller HTML, CSS och Javascript.
